📦
تعريف المنتج — product
أنشئ منتجاً بجميع خصائصه التجارية بكلمة واحدة.
product عطر_سهيل {
  price: 450
  currency: "SAR"
  stock: 100
  category: "عطور"
}
🛒
سلة التسوق — cart
أنشئ سلة تسوق وأضف منتجات بكميات مختلفة.
cart سلتي {}
add(سلتي, عطر_سهيل, 2)
checkout(سلتي)
💰
الخصومات — discount
طبّق خصومات بنسب مئوية أو قيم ثابتة على أي منتج.
discount عرض_الصيف {
  percent: 20
  apply_to: "عطور"
}
👤
العميل — customer
عرّف بيانات العميل ومستوى عضويته بسهولة.
customer أحمد {
  tier: "VIP"
  loyalty_points: 500
}
📊
الطباعة والتقارير — show / report
اعرض أي قيمة أو أنشئ تقرير مبيعات كامل.
show(عطر_سهيل.price)
report(سلتي)
show("إجمالي المبيعات")
🔁
الشرط والتكرار — if / loop
منطق برمجي كامل داخل سياق المتجر.
if (عطر_سهيل.stock > 0) {
  show("متوفر")
} else {
  show("نفذ المخزون")
}
